# Security Policy

## Supported Versions

Only the latest published version of `@arjanj/loupe` is actively supported with security fixes.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities privately through GitHub Security Advisories:
https://github.com/ArjanJ/loupe/security/advisories/new

Include a clear description of the issue, steps to reproduce (or a minimal proof of concept), and the affected version. You can expect an initial response within a few days.
